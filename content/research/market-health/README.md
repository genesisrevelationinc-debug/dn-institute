# 🌰 Market Health Research

This directory contains research articles and datasets documenting instances and methods of market manipulation in cryptocurrency markets. Our goal is to provide data-driven, statistically significant analysis of market health metrics.

## 🌰 Contributing

We welcome contributions that:
- 🌰 Document sophisticated market manipulation techniques with original data analysis
- 🌰 Add real-world examples with supporting datasets and visualizations
- 🌰 Improve existing content with additional metrics and orderbook snapshots
- 🌰 Fix factual errors and enhance documentation

## 🌰 Directory Structure

Each article should be in its own directory with:
- 🌰 `index.md` - Main article content
- 🌰 `data/` - Supporting datasets (CSV, JSON, etc.)
- 🌰 `images/` - Visualizations and graphs
- 🌰 `README.md` - Brief description of findings
